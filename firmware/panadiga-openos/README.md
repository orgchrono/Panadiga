## Architecture & SDRAM Boot Model (`SA0..SA10` IPL Permanently Untouched)

`Panadiga OpenOS` replaces proprietary `PiE-OS` strictly inside **volatile SDRAM** via
`Loader ver0.61` Stage-1.5 (`DIGADIAG.FRM` raw `262,144 B` at `0x5040_0000`) and Stage-2
(`0x5700_0000`, `16 MiB` SDRAM window):

| Memory Slot | Address Span | Role |
| :--- | :--- | :--- |
| **IPL Read-Only** | `0x8000_0000..0x8003_FFFF` / `0x8400_0000..0x8403_FFFF` (`SA0..SA10`) | **NEVER modified (`E05`)**; preserves stock P7501 & SD recovery |
| **Stage-1.5 RAM** | `0x5040_0000..0x5047_FFFF` (`512 KiB`) | `crt0_am34.S` -> `openos_kernel_entry()` early bring-up & Stage-2 chainloader |
| **Stage-2 OS** | `0x5700_0000..0x57FF_FFFF` (`16 MiB`) | Full open-source drivers, filesystem, video TBC, and interactive shell |

## Non-Negotiable Hardware Invariants

1. **Lethal MMIO Barrier:** Never read or write **`0xC000_100C..0xC000_100F`** (hard bus/WDT hang)
   or **`0xDC0F_0000..0xDC0F_0FFF`** (`SYSCON` danger aperture). Enforced in `hal/am34_mmio.h`.
2. **Permanent IPL Lockout:** Any write into CS0/CS1 `SA0..SA10` (`256 KiB`) is blocked by
   `am34_mmio_is_forbidden()`.
3. **`IC7501` Front-Panel TBUS Keepalive:** `0xDC01_0000..0xDC01_001F` must transmit the `255 s`
   heartbeat frame (`[0x8A, 0x02, 0x00, 0xFF, ..., 0x30]`) before ~44 s elapses so standby MCU
   `IC7501` does not pull down the main SMPS rails.
4. **SATA Bridge Post-Reset Margin:** `DAVIS` CH1 (`0x8900_0C00`) uses an active-HIGH reset and
   must wait `1000 ms` (`OPENOS_SATA_BRIDGE_WAIT_MS`) before `BSY`/`DRDY` polling when a StarTech
   `IDE2SAT2` (`88SA8052`) bridge is attached.
5. **Default Broadcast Standard (`NTSC` Option Available in PiE-OS / OpenOS):** `AIOF` defaults
   to **`OPENOS_TV_NTSC` (`VMODESEL = 0x8020`)** with runtime switching to **`OPENOS_TV_PAL_M` (`0x8021`)**
   and **`OPENOS_TV_PAL` (`0x8027`)**.

## Incremental Bring-Up Roadmap (`M0 -> M4`)

| Milestone | Scope | Gate to Advance |
| :--- | :--- | :--- |
| **`M0`** | `boot/am34_sdram.ld`, `crt0_am34.S`, `SC0` UART0 (`115200 8N1`), safe HAL | Boot at `0x5040_0000` via `DIGADIAG.FRM`; `OPENOS>` banner on `P7501` |
| **`M1`** | `IC7501` `TBUS` 255s keepalive + VFD display + IR RX decode | Stable rail uptime > 10 min without ~44 s `IC7501` power drop |
| **`M2`** | `IIC1` (`IC3001`: `BH7629KS2` `0x90/0x92` BR/NA vs `C1AB00002379` `0x94` EC) + `AIOF` TBC + `AVDD` DAC/colorbar | Clean `NTSC` (`0x8020`) / `PAL-M` (`0x8021`) S-Video color bar & TBC output |
| **`M3`** | `SDCD` 4-bit FAT16 + `DAVIS` CH0/CH1 ATA (`1000 ms` bridge wait) + `storage_provisioner` FCIS (`M FIRM -> MAIN -> UPDATE -> UPDOK -> FINISH`) | Deterministic auto-sized MEIHFS layout (`5 GB..2 TiB`) + Stage-2 load to `0x5700_0000` |
| **`M4`** | `AVFE` / `MPE4` MPEG-2 encoder/decoder + audio DSP | Capture & playback open-source DVR stream without Panasonic proprietary blobs |

## Interactive `OPENOS>` Declarative Shell (`kernel/openos_main.c`)

Dispatched declaratively from `k_shell_cmds[]` (SSOT introspected by `scripts/generate_tool_arsenal.py`), driven by non-blocking `SC0` RX polling (`SC0STR 0xD400_200C & 0x0010` -> `SC0RXB 0xD400_2009`) in `openos_shell_poll_once()` with bounded 65,536-poll idle `IC7501` `255s` TBUS keepalive:

- **Core & SSOT:** `help`, `status`, `wdt`, `sata`, `vfd <7ch>`, `ssot` (prints `OPENOS_SSOT_CONTRACT_HASH = C045CA85` generated by `panadiga ssot export-all` into `generated/openos_ssot.h`, plus `hal/am34_mmio.h` `am34_mmio_read8` with lethal MMIO barriers)
- **Read-Only Hardware Triage (`M3`):** `sd` (`drivers/sdcd_sd.c` inspecting `SDCD 0x8900_1800` + `SDCD_CFG4 0x8900_1850` bit-15 4-bit/1-bit bus mode), `bgo` (`drivers/nor_bgo_ro.c` inspecting NorAutoboot `SA11 0x8404_0000`, 45 `SA26..SA70` BGO headers, and `EEMUL SA134 0x847F_0000` `"1284"`)
- **Video & TBC:** `ntsc`, `palm`, `pal`, `tbc on`, `tbc off`, `video br`, `video ec`, `video probe`, `dac on`, `dac off`, `colorbar on`, `colorbar off`
- **Full-Storage Auto-Provisioner:** `provision` (`openos_storage_plan_compute` pure FCIS auto-sizer + `M FIRM -> MAIN -> UPDATE -> UPDOK -> FINISH` thin execution shell with `IC7501` 255s keepalive and `DAVIS CH1` `1000 ms` reset margin)

*(Target hardware note: `EV-20261124-004` live `COM10` readback confirmed `SDCD_CFG4 0x89001850 = 0x000040B8` (`4BIT` mode with SD inserted), `TBUS_MBX0 0xDC010010 = 0x840000A3`, `BGO` 45/45 healthy, and `SA11 0x84040000 = ERASED_FF` ready for either SDRAM `DIGADIAG.FRM` OpenOS bring-up or opt-in NOR autoboot SD-less install.)*
