### Active Probe Capabilities (`p7501_cli_help.c`, Zero External Gadgets)
- **Nibble-LUT CRC32, `VAULT VERIFY`, `IR VERIFY` & `DUMPNOR ff_blocks` (v0.2.0):**
  - `p7501_crc32_ieee_update()` (`common/p7501_crc_csum.c`) with a 16-entry nibble lookup table + `p7501_buf_is_all_ff()`/`p7501_buf_count_non_ff()` shared by `p7501_qspi_crc32_fast()` (`flash/p7501_qspi_hal.c`);
  - **`VAULT VERIFY <1..3>`** (`flash/p7501_vault.c` / `flash/p7501_vault_codec.c`): audits CRC32 and `non_ff` count for payload slots `1..3`, emitting `sub=VERIFY slot=... crc32=0x... non_ff=...` in `@P7501_RES`;
  - **`IR VERIFY <12hex>` / `IRTX` / `IRRX`** (`diag/p7501_ir_codec.c` / `cli/p7501_cli.c`): validates Panasonic OEM bytes (`0x02, 0x20`), vendor parity nibble, and XOR checksum `dev ^ sub ^ cmd`, emitting `mode=VERIFY frame=... parity=OK|ERR` with zero extra probe hardware;
  - **`DUMPNOR` / `FAST_DUMPNOR` / `DUMPNOR_RESUME` (`ff_blocks`):** `p7501_dumpnor_ff_tracker_t` tracks blank 512 B (`0xFF`) blocks inline and emits `ff_blocks=<u32>` on `@P7501_RES` and `PANARSP:`.
- **`DIAGWATCH` Monitor & Unlock:** Supports simple actions (`AUTO`, `BYPASS`, `FORMAT`, `DUMP`, `QUIT`, `NONE`), two-step Upper-NOR governance (`NORUNLOCK:CONFIRM_UPPER_NOR` / `NORLOCK` dispatching `'U'` → `'W'`/`'E'` on `PANAMON1>`), and **parameterized actions** (`READ[:a[,n]]`, `WRITE:<a,v>`, `JUMP:<a>`, `ERASE:<a_nvram>`) with **fail-closed (`E05`) guards**:
  - The opening `256 KiB` (`0x80000000..=0x8003FFFF` and `0x84000000..=0x8403FFFF`, denoted `SA0..SA3` in abstract `64 KiB` Pico policy units and physically `SA0..SA10` = `8×8 KiB + 3×64 KiB` on the Spansion `S29JL064H`) is **permanently read-only (`immutable RO`, never writable → `E05`)**; the Upper NOR window (`0x80040000..=0x807EFFFF` and `0x84040000..=0x847EFFFF`, `SA4..SA133` in policy / physically `SA11..SA133`) stays **write-protected by default (`NorWritePolicy::NvramOnly` → `E05`)** until explicit `CONFIRM_UPPER_NOR` opt-in (`p7501_flash_is_protected_ipl_range` / `p7501_flash_is_nvram_microsector_addr`).
- **`_dev_SERIAL` Debugger (`PANARSP`):** Supports `REGS` (12 MN103S registers decoded from 96 little-endian hex chars in `p7501_rsp_decode_mn103_regs`), `MEM`, `WMEM`, `DUMPNOR`, `CALL`, `NORUNLOCK:CONFIRM_UPPER_NOR` / `NORLOCK`, and JEDEC SRAM stub commands at `0x51800000` (`JEDEC_ERASE:<addr>`, `JEDEC_PROG:<addr>,<hex>` → `PANAJEDEC_OK` / `PANAJEDEC_TO`).
- **Optical Drive Factory Console (`DRVPANA`):** Executes `Matshita R6-MV4` front-end commands with optional automatic `PASS 0x4d415453 0x48495441` unlock (or `NOPASS`).
- **Timing & SD Analyzers (`PIO0`/`PIO1`):** Passive `SDSNIFF` on `GP10..GP15` (CRC16/lane), `JIGSWEEP`, `PIOLOGIC`, `BOOTTRACE`, `PWRTRACE`, `WAITTX`, `BAUDSCAN`, and `HEXCAP`.
- **C11 Fast Streaming Offload & Push Progress (`67` SSOT commands — `[PROVEN ON REAL HARDWARE]` on `COM10`):** `NOR_MAP` (`3.31 s` across all 142 sectors `SA0..SA141`, `18` `@P7501_PROG phase=MAP` push frames, `healthy=YES`, `NSW5V_DROPS=0`), `FAST_READ` (on-demand upload of the verified `606 B` MN103S binary stub at `0x9043A000`, `CRC32 0x3D2D3D4A`, streaming `4,096 B` from `0x84000000` in `0.518 s` warm = `~7.9 KiB/s`, `CRC32 0x8AB25B4E` byte-identical to `eh55_loader_ver061_256k.bin[:4096]`), and `FAST_WRITE` (permanent `E05 IPL_LAYER1_RO` lockout on `0x84000000`, on-Pico `1 -> 0` monotonicity guard, and unconditional `U LOCK`), with `@P7501_PROG` push frames parsed by `panadiga-core::pico::prog_event` and streamed via event-driven React listeners (`PipelineStepRunner` live `SAxx`, `KiB/s`, and `ETA`, zero polling).

## 5. Physical Safety Invariants & Quality Verification

1. **Electrical Safety (`VEP79138` / `P7501`):** `GP3` (`NSW5V`) ALWAYS in **Hi-Z Input**; logic ceiling `<= 3.35 V`; `GP5` (`XRESET`) strictly open-drain (`0 V` / `Hi-Z`); `SW_UART` (`GP26`) held in `ADC0 Hi-Z` outside controlled `JIG:<ms>` windows.
2. **Two-Layer NOR Write Protection (`IC5001` Spansion `S29JL064H`):** Layer 1 IPL (`256 KiB`: `0x80000000..=0x8003FFFF` and `0x84000000..=0x8403FFFF`, labeled `SA0..SA3` in abstract `64 KiB` Pico policy units / physically `SA0..SA10` = `8×8 KiB + 3×64 KiB` on silicon) is **permanently read-only (`immutable RO`, never writable → `E05`)** on the Pico probe; Layer 2 BGO/App Upper NOR (`0x80040000..=0x807EFFFF` and `0x84040000..=0x847EFFFF`, `SA4..SA133` in policy / physically `SA11..SA133`) remains write-protected by default (`NvramOnly` → `E05`), unlockable only via explicit `CONFIRM_UPPER_NOR` opt-in / CoW `panadiga nvram patch-upper-nor` (and guarded by RAG `HardwareSafetyValidator`).
3. **Ghidra Database Integrity:** `C:\ghidra\projects\Panadiga_MN103S` is never modified by tests, CLI runs, or CI checks.
4. **9 Quality Gates Pipeline ([`scripts/validate.py`](./scripts/validate.py)):** Rust (**6 crates**, `fmt`/`clippy`/`337` tests), TypeScript (`oxlint` + `tsc --noEmit`), Vitest (`128` tests / `39` files), `jscpd` (`0%` clones), `uxlint` (`100/100` across `386` files), Playwright E2E (`27` tests / `9` specs), Ghidra Jython export (`panadiga ghidra export-all`), C11 host tests (`38` test suites/functions across `4` modules with `-Wall -Wextra -Werror` / `/W4 /WX` + ARM RP2040/RP2350 check), and Python (`py_compile`, `mypy --strict` `46` files, `pytest` `32` tests across `6` files).
